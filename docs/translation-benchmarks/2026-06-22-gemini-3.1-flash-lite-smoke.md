# Gemini 3.1 Flash Lite — smoke benchmark

- Date: 2026-06-22
- Model: `google/gemini-3.1-flash-lite`
- Group: `smoke`
- Translation pipeline: 5/5 completed
- Source detection: 6/10 matched
- Database persistence: none; Wiktionary context was read only

## Overall assessment

The model completed every structured translation request and preserved the requested output shape. Primary translations were generally accurate and readable. The strongest results were the formal German request and the English idiom. The main translation-quality weaknesses were secondary metadata, context drift in examples, and pluralization around an immutable numeric placeholder.

The source-language detector is not ready to silently resolve short ambiguous inputs. Four of ten smoke cases made an overconfident selection where the expected behavior was to ask the user.

## Translation analysis

### `bank` — English to Czech

Primary translation: `břeh`

Verdict: correct primary meaning. The model used the river-bank sense rather than the financial sense and provided useful Russian guidance.

Issues:

- The pipeline returned `needsReview: true`, meaning deterministic validation still failed after retries.
- `stráň` is a questionable synonym for a general river bank.
- `pobřeží` is less natural than `břeh` for an ordinary river bank.
- The third example switches to `u vody` and no longer demonstrates the assigned primary translation.

### `Break a leg!` — English to Russian

Primary translation: `Ни пуха, ни пера!`

Verdict: strong idiomatic equivalent. Register and theatrical context were preserved.

Issues:

- `В добрый путь!` is not a good alternative before a performance.
- Some explanatory metadata overstates the requirement to answer `К чёрту!`.
- The literal explanation of the Russian idiom is imprecise.

### `That party was lit.` — English to Czech

Primary translation: `Ta párty byla totální pecka.`

Verdict: natural, readable colloquial Czech. Meaning and positive intensity were preserved.

Issues:

- `naprostý masakr` is considerably stronger and more context-dependent.
- The alternatives trend toward increasingly aggressive slang rather than equal variants.

### Formal German request — German to English

Primary translation: `Would you be so kind as to send me the documents by Friday?`

Verdict: pass. Politeness, deadline, and business register were preserved.

### Placeholder preservation — English to Czech

Primary translation: `Dobrý den, {name}. Máte {{count}} nepřečtených zpráv.`

Verdict: placeholders were preserved byte-for-byte, but the localization is not production-safe for every count.

Issues:

- `nepřečtených zpráv` only fits some Czech plural categories; `1` and `2–4` require different forms.
- `Dobrý den` makes the greeting more formal than the source `Hello`.
- A production localization string needs plural-aware message variants rather than one fixed sentence.

## Recommendation

Proceed with the full translation benchmark: structured generation works with this model. Do not yet rely on automatic source selection for short words, close-language vocabulary, or transliteration. Those cases should display an explicit source-language choice.
