# T01 — Валидатор сессии убивает режим mentor

- **Приоритет:** P0 (Critical)
- **Фаза:** 0 — Немедленно
- **Оценка:** ~0.5 дня
- **Зависит от:** —
- **Блокирует:** —
- **Связано:** [T22](T22-refactor-translate-helper-di.md) (рефактор сессии), [T29](T29-core-hygiene-batch.md) (чистка `SessionData`)
- **Находки:** C1, B1

## Проблема

`apps/bot/src/session-storage.ts:16` — `VALID_MODES = new Set(["idle", "translate"])`, тогда как `apps/bot/src/types.ts:20` объявляет `UserMode` с `"mentor"`. После `/mentor` в сессию пишется `activeMode: "mentor"` (`scenes/mentor.scene.ts:20`); на следующем апдейте `isValidSessionData` возвращает `false` → «Resetting corrupt bot session» → **вся сессия удаляется**. Следствия: ментор теряет историю после каждой реплики (амнезия), стираются `translationMap` и все pending-состояния. Роутинг выживает только потому, что `middlewares/auth.ts:36-41` регидрирует режим из БД.

## Затронутые файлы

- `apps/bot/src/session-storage.ts:16` — `VALID_MODES`.
- `apps/bot/src/types.ts:20` — источник истины `UserMode`.

## Решение

1. Вывести `VALID_MODES` из типа `UserMode`, а не хардкодить: единый массив-источник, из которого строится и union, и `Set` — чтобы новый режим нельзя было забыть.
2. Заменить деструктивное удаление сессии на неразрушающую миграцию по `BOT_SESSION_VERSION`: при неизвестной версии/поле — чинить/дефолтить конкретное поле, а не выбрасывать всю сессию.

## Критерии приёмки

- [ ] После `/mentor` и нескольких реплик история ментора сохраняется между апдейтами.
- [ ] `translationMap` не обнуляется при переключении в mentor и обратно.
- [ ] Добавление нового значения в `UserMode` без обновления `VALID_MODES` ловится компилятором или тестом.

## Тесты (spec-first)

- Behavior-тест: сессия с `activeMode: "mentor"` проходит `isValidSessionData` (параметризовать по **каждому** члену `UserMode` — exhaustiveness).
- Тест на неразрушающую миграцию: сессия со старой версией/лишним полем чинится, а не удаляется целиком.

## Примечания

Однострочный фикс с несоразмерно большим эффектом. Делать первым — он же разблокирует корректное тестирование mentor-флоу для [T16](T16-unified-ai-credit-metering.md).
