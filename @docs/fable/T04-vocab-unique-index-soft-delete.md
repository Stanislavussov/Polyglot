## Проблема

`packages/adapters/db/src/schema.ts:178` — уникальный индекс `ve_user_original_sourcelang_idx` на `(user_id, original, source_lang_id)` **без** `WHERE is_active`. Проверка дубликата `findByOriginalAndSource` (`vocabulary.repository.ts:132-160`) фильтрует `isActive = true`, а удаление слова через уведомление — soft-delete (`notification.callbacks.ts:119`, строка остаётся). Сценарий: пользователь удаляет слово → сохраняет то же слово снова → проверка дубликата возвращает `null` (старая запись неактивна) → `create()` бьётся об уникальный индекс необработанным исключением `23505`.

## Затронутые файлы

- `packages/adapters/db/src/schema.ts:178` — индекс.
- `packages/adapters/db/src/repositories/vocabulary.repository.ts:132-160` — проверка дубликата и создание.
- Новая миграция в `packages/adapters/db/drizzle/`.

## Решение

Выбрать один из двух подходов (предпочтителен второй):

1. Сделать индекс частичным: `WHERE is_active` — тогда неактивные дубликаты не конфликтуют. Но останется «мёртвая» неактивная строка + потеря её истории.
2. **Реактивация вместо insert:** при сохранении искать запись без фильтра `isActive`; если найдена неактивная — реактивировать (`isActive = true`, обновить поля), иначе создавать. Либо `onConflictDoUpdate` по существующему уникальному ключу. Сохраняет SRS-историю (перекликается с [T18](T18-check-then-insert-races.md)/E8 про `updateAllTranslations`).

Схема БД меняется через `pnpm db:generate` → ревью миграции → `pnpm db:push` (на `develop` — только push, не migrate; см. CLAUDE.md Hard Rule #3).

## Критерии приёмки

- [ ] Удаление слова и повторное сохранение того же слова не бросает исключение.
- [ ] Повторное сохранение реактивирует запись (или создаёт корректно), без дублей.
- [ ] Учтён регистр/нормализация (см. E9 в [T18](T18-check-then-insert-races.md)) — «Hello» и «hello» не плодят дубли, если lookup их нормализует.

## Тесты (spec-first)

- Integration-тест: create → soft-delete → create снова → одна активная запись, без исключения.
- Тест сохранения SRS-истории при реактивации (если выбран подход 2).
