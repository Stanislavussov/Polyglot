# T03 — Убрать cast контейнера, выровнять `estimateCost`

- **Приоритет:** P0 (Critical — скрытый рабочий баг + отключённый типовой контроль)
- **Фаза:** 0 — Немедленно
- **Оценка:** ~0.5 дня
- **Зависит от:** —
- **Блокирует:** —
- **Связано:** [T21](T21-single-source-of-truth.md) (цены моделей)
- **Находки:** C3

## Проблема

`apps/bot/src/container.ts:101` — композиционный корень собирается через `} as unknown as ServiceContainer`. Двойной cast **полностью выключает** проверку соответствия реализаций контрактам портов. Это уже прячет реальный баг: `packages/core/src/ports/ai.port.ts:40` требует `estimateCost(inputTokens, outputTokens, modelId)`, а реализация `packages/adapters/ai/src/models.ts:98` имеет сигнатуру `estimateCost(tokens, model)`. При вызове через порт `outputTokens` (число) передаётся как имя модели → `findModel` возвращает `undefined` → молча считается дефолтная цена. Любой будущий дрейф между портами и адаптерами (репозитории, `languageCache`) тоже пройдёт незамеченным.

## Затронутые файлы

- `apps/bot/src/container.ts:101` — cast.
- `packages/core/src/ports/ai.port.ts:40` — контракт `estimateCost`.
- `packages/adapters/ai/src/models.ts:98,111` — реализация (`estimateCost` и уже существующий подходящий `calculateCost`).

## Решение

1. Заменить `as unknown as ServiceContainer` на явную типизацию: `const container: ServiceContainer = { … }`. Компилятор покажет все реальные расхождения.
2. Выровнять сигнатуру `estimateCost` в адаптере под порт (`inputTokens, outputTokens, modelId`). В адаптере уже есть подходящий `calculateCost` (`models.ts:111`) — свести к нему.
3. Устранить любые прочие несоответствия, которые вскроет снятие cast (репозитории, порт кэша языков).

## Критерии приёмки

- [ ] `container.ts` типизирован как `ServiceContainer` без `as unknown`.
- [ ] `pnpm build` проходит — то есть все реализации реально соответствуют портам.
- [ ] `estimateCost` считает стоимость по корректной модели (не дефолтной) — проверено тестом.

## Тесты (spec-first)

- Unit-тест `estimateCost`: для известной модели с известной ценой возвращает корректную стоимость по `(inputTokens, outputTokens, modelId)`, а не дефолт.
- Компиляция без cast — сама по себе регрессионный тест контрактов.

## Примечания

Снятие cast может вскрыть дополнительные несоответствия — заложить время на их починку. Это профилактика повторения инцидентов, связанных с учётом стоимости и выбором модели.
