# T11 — Guard на удаление/смену default AI-модели

- **Приоритет:** P1 (High — прямой родственник инцидента 429)
- **Фаза:** 1 — Безопасность
- **Оценка:** ~1 день
- **Зависит от:** —
- **Блокирует:** [T21](T21-single-source-of-truth.md) (промежуточная защита до единого источника правды)
- **Связано:** [T16](T16-unified-ai-credit-metering.md)
- **Находки:** D2

## Проблема

`apps/admin-api/src/routes/ai-models.ts:246-254` — `DELETE /ai-models/:id` удаляет что угодно, включая текущую default-модель; `set-default` (`ai-models.ts:229-244`) не проверяет, что модель включена и существует на OpenRouter. При удалении используемой модели бот падает на захардкоженный fallback `"openai/gpt-5-nano"` (`packages/core/src/modules/settings/settings.service.ts:282`), который может быть недоступен — тот же класс отказа, что инцидент с зависанием на `:free`-модели.

## Затронутые файлы

- `apps/admin-api/src/routes/ai-models.ts:229-254`.
- `packages/core/src/modules/settings/settings.service.ts:282` — fallback.

## Решение

1. Запретить удаление default-модели → 409, пока не назначена другая.
2. При `set-default` требовать `isEnabled = true` и валидировать доступность модели на OpenRouter (или хотя бы существование в реестре).
3. Пересмотреть захардкоженный fallback: сделать fallback-цепочку конфигурируемой (перекликается с B15 «нет fallback-модели», [T30](T30-longtail-cleanup.md)) — минимум убедиться, что fallback гарантированно доступен.

## Критерии приёмки

- [ ] Удаление текущей default-модели → 409 с понятным сообщением.
- [ ] `set-default` на выключенную/несуществующую модель отклоняется.
- [ ] Аудит-лог изменений моделей (`logAiModelChange`) продолжает писаться.

## Тесты (spec-first)

- Integration-тест: попытка удалить default → 409; удаление не-default → 200.
- Тест: `set-default` на `isEnabled=false` → 4xx.

## Примечания

Кэш настроек 60 с (`settings.service.ts:14`) — изменения долетают до бота за минуту, это приемлемо. Аудит-лог уже сделан хорошо — не ломать. Это тактическая защита; системно источник моделей/цен переезжает в БД в [T21](T21-single-source-of-truth.md).
