# T02 — Доделать и укрепить незакоммиченный diff out-of-set

- **Приоритет:** P0 (Critical — есть незакоммиченные изменения в working tree)
- **Фаза:** 0 — Немедленно
- **Оценка:** ~1 день
- **Зависит от:** —
- **Блокирует:** [T22](T22-refactor-translate-helper-di.md) (тот же файл будет распилен — diff должен лечь раньше)
- **Связано:** [T01](T01-mentor-session-validator.md)
- **Находки:** B9

## Проблема

В working tree лежит незакоммиченный diff, закрывающий известную дыру «out-of-set языков» (`kk`/`sk` проскакивали мимо блокировки). Функционально diff хорош и переиспользует существующий флоу, но содержит три дефекта, которые нельзя коммитить как есть:

1. **Нелокализованные строки** — `translate-mode.helper.ts:325,335,351` («Session expired…», «You've reached the maximum number of languages…») захардкожены по-английски, при том что сам diff аккуратно добавил i18n-ключи во все 11 локалей.
2. **Конфляция ошибок** — `translate-mode.helper.ts:348-355`: **любая** ошибка `updateLearningLangs` (включая падение БД) показывается как «достигнут максимум языков».
3. **Single-slot race** `pendingOutOfSet` — `translate-mode.helper.ts:331,374`: язык берётся из callback data кнопки, слово — из единственного слота сессии. Два подряд out-of-set промпта (испанское слово, затем португальское) → тап по старой кнопке добавит один язык, но переведёт слово другого.

Плюс `tr:oos` не добавлен в реестр контрактов `callbacks/contracts.ts` (документация-как-код по restart-safety).

## Затронутые файлы

- `apps/bot/src/scenes/helpers/translate-mode.helper.ts` (working tree).
- `apps/bot/src/callbacks/contracts.ts` — реестр callback-контрактов.
- Locale-файлы (ключи уже добавлены — использовать их).

## Решение

1. Заменить захардкоженные строки на `t("staleSession")` / `t("maxLanguagesReached")` (ключи уже в локалях).
2. Проверять лимит языков **явно до** вызова `updateLearningLangs`, либо ловить типизированную ошибку лимита отдельно от прочих; ошибку БД показывать как generic-ошибку.
3. Убрать single-slot race: класть слово в callback data-ключ (по образцу `translationMap`), либо сверять `pending.lang === sourceLang` перед применением; после выбора убирать клавиатуру (edit reply markup), чтобы старые кнопки не срабатывали.
4. Зарегистрировать `tr:oos` в `callbacks/contracts.ts`.

## Критерии приёмки

- [ ] Все пользовательские строки нового флоу локализованы во всех поддерживаемых языках.
- [ ] Падение БД при добавлении языка не маскируется под «достигнут максимум».
- [ ] Два подряд out-of-set промпта не путают язык/слово; старые кнопки после выбора неактивны.
- [ ] `tr:oos` присутствует в реестре контрактов.

## Тесты (spec-first)

- Behavior-тест double-prompt: два разных out-of-set слова подряд → выбор по каждой кнопке добавляет правильный язык и переводит правильное слово.
- Тест разделения ошибок: мок `updateLearningLangs` бросает не-лимитную ошибку → пользователь видит generic-ошибку, а не «максимум языков».
- Тест локализации: строки резолвятся через `t()` (нет литералов).

Приоритет высокий именно потому, что изменения уже в рабочем дереве. Закоммитить укреплённую версию до старта [T22](T22-refactor-translate-helper-di.md), иначе конфликт с распилом файла.
