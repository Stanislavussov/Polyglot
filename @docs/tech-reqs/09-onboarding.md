# Onboarding (4 steps)

```
/start
  │
  ├─ Step 1: Which language to continue in?
  │          (bot interface language)
  │          inline keyboard: 🇷🇺 Russian | 🇬🇧 English | 🇨🇿 Čeština | ...
  │
  ├─ Step 2: What is your native language?
  │          inline keyboard: same languages
  │          (may differ from interface language)
  │
  ├─ Step 3: Which languages are you learning?
  │          multi-select inline keyboard (1–4 languages)
  │          ✅ Done button when selection is made
  │
  └─ Step 4: Demo translation
              │
              └─ User enters any word
                 Bot shows full result in all selected languages
                 "Save to dictionary?" → [Yes] [No]
                 → Onboarding complete, show main menu
```
