## 3. Ошибки

11 error-строк, 58 warn. Пользователь увидел ошибку **3 раза**: «в отличие от», «честный»,
«narradora». Все три — одна цепочка:

```
gemini-3.1-flash-lite → timeout ровно 10 000 мс
   ↓ failover
openai/gpt-5-nano     → timeout ровно  5 000 мс
   ↓
AITimeoutError → 15–16 с ожидания и ошибка
```

| model | kind | success | n | avg ms |
|---|---|---|---|---|
| gemini-3.1-flash-lite | object | ✅ | 169 | 1 478 |
| gemini-3.1-flash-lite | text | ✅ | 29 | 996 |
| gemini-3.1-flash-lite | object | ❌ | 4 | 10 004 |
| **openai/gpt-5-nano** | object | ❌ | **4** | 3 843 |

**Фоллбэк-модель: 4 попытки, 0 успехов.** Две причины:

1. **Схема нелегальна для строгого structured output OpenAI.** Один отказ прилетел за
   365 мс: `Invalid schema … 'required' … Missing 'native'`. В
   `translation.schema.ts:22` — `native: z.string().min(1).nullish()`; опциональное поле не
   попадает в `required`, и Azure отвергает такую схему **всегда**. Gemini её проглатывает.
2. **Бюджет фоллбэка вдвое меньше.** `ai-model.ts:76`: при `B = 15 000` primary получает
   10 с, фоллбэк — 5 с. Модели, вызванной потому что первая не уложилась, дают вдвое
   меньше времени.

Таймаут-рейт основной модели: 4 из 202 = **2%** — приемлемо.
→ [Task 73](../../tasks/73-ai-failover-repair.md)

Главный результат разбора.

**Autoheal мёртв 3 дня.** `polyglot_autoheal` рестартует раз в 60 с:

`willfarrell/autoheal:1.2.0` (`deploy/docker-compose.yml:160`) не содержит бинарник в PATH.
Сторож, который должен перезапускать зависший бот, не отработал ни секунды.

**Алерты: 7 правил, рабочих 3.**

| Алерт | Состояние |

| `AI model circuit breaker open` | метрики `bot_ai_circuit_state` **не существует**, `or vector(0)` маскирует → сработать не может |

**cAdvisor не видит контейнеры:** у `container_memory_working_set_bytes` метки только

system monitoring» и любой контейнерный алерт слепы.

**Дашборд «Polyglot Bot» показывает пустоту:** панели ссылаются на несуществующие
`bot_ai_requests_total`, `bot_ai_tokens_total`, `bot_notifications_total`,
`bot_mentor_requests_total`. Из 4 серий панели «Error Rate (All Sources)» три мертвы —
панель пуста даже во время реального отказа.

Мелочи: `bot_active_users_total` = 0 (gauge не обновляется); в метке Loki `level` лежат
